# 使い方

intro-bot の運用ガイド。Bot 招待後の設定方法、メンバー目線の動作、管理者向けスラッシュコマンドの解説。

セットアップ(環境変数 / デプロイ)は [README.md](../README.md) を、内部仕様は [SPEC.md](../SPEC.md) を参照。

## Bot をサーバーに招待する

Discord Developer Portal の **OAuth2 → URL Generator** で以下を選択して生成された URL からサーバーに追加する。

### Scopes

- `bot`
- `applications.commands`(スラッシュコマンドに必要)

### Bot Permissions

- `View Channels`
- `Send Messages`
- `Embed Links`
- `Read Message History`

サーバー全体に上記権限を付与しておけば、自己紹介チャンネルと各 VC の text-in-voice の両方で動作する。チャンネル単位で個別にオーバーライドしている場合はそちらも確認する。

## メンバーの使い方

メンバーは「自己紹介チャンネル」に **本文ありの** メッセージとして自分の自己紹介を投稿する。

- Bot は **本文が空でない最新の投稿** を自己紹介として採用する
- 添付のみ(本文なし)のメッセージは自己紹介として扱われない
- 自己紹介を更新したい場合は、新しいメッセージとして再投稿するか、既存メッセージを編集する

その後、対象サーバーの VC に入室すると、その VC のテキストチャットに自分の自己紹介が自動で埋め込み投稿される。

## 動作の挙動

| 動作 | 投稿される? |
|------|-------------|
| VC に新規入室 | ✅ |
| VC 間を移動 | ✅(移動先に投稿) |
| VC を退室 | — |
| 同一 VC 内でミュート/配信開始/カメラ ON 等 | — |
| ステージチャンネルへ入室 | — (対象外) |

### クールダウン

同一ユーザーが連続で VC を出入りしても投稿が連投されないよう、ユーザー単位で **デフォルト 1 時間(3600 秒)** のクールダウンが設定されている。

- スコープは **ユーザー単位 + 全 VC 横断**
- A VC に入って投稿 → 5 分後に B VC へ移動しても、B には投稿されない
- 連投抑止を優先する設計上のトレードオフ
- クールダウンは「埋め込み投稿が成功した時刻」から起算。投稿失敗・自己紹介未登録の場合はリセットされない
- Bot が再起動するとクールダウン状態はリセットされる(設定値そのものは Postgres に永続化)

### 通知抑制

埋め込み内のメンションは表示されるが、実際の通知は飛ばない(`allowed_mentions=False`)。

## 管理者向けスラッシュコマンド

`Administrator` 権限を持つメンバーのみが実行可能。Discord クライアント側で非管理者には表示されないが、コード側でも二重に検証している。

### `/intro-config show`

現在の設定を **ephemeral**(自分にしか見えないメッセージ)で表示する。

```
intro_channel: #自己紹介
cooldown_seconds: 3600
```

### `/intro-config intro-channel <channel>`

自己紹介チャンネルを変更する。

- 新しいチャンネルは `TextChannel` のみ選択可能
- 変更時にメッセージキャッシュ(ユーザーID → メッセージID の対応)がクリアされ、次回の VC 入室時に新しいチャンネルから履歴を再走査する
- 変更内容は DB(`bot_config` テーブル)に永続化される

### `/intro-config cooldown <seconds>`

クールダウン秒数を変更する。

- 値の範囲は **1〜86400 秒**(1 秒〜1 日)
- 即時反映。すでに最終投稿から経過した時間にそのまま新しい閾値が適用される(例: 30 分前に投稿したユーザーがいる状態で 1800 秒に変更すると、その時点でクールダウンが解除される)
- 変更内容は DB に永続化される

## トラブルシューティング

| 症状 | 確認ポイント |
|------|---------------|
| VC 入室しても投稿されない | Bot に対象チャンネル(自己紹介・VC 両方)の権限があるか / クールダウン中ではないか / そもそも自己紹介を投稿しているか |
| `/intro-config` がメニューに出ない | サーバー管理者権限を持っているか / Bot 招待時に `applications.commands` scope を含めたか |
| 自己紹介を編集しても反映されない | Bot は次回 VC 入室時に最新の本文を取得する。すぐ確認したい場合は VC を一度退室して再入室(クールダウン中なら時間を置く) |
| 埋め込みの末尾に `…` が付いている | 自己紹介本文が 4000 文字を超えたため切り詰められている。フィールドの「ジャンプ」リンクから元投稿へ飛べる |
| ステージチャンネルで動作しない | 仕様(対象外) |
| 設定変更後も古い値で動作している | DB 接続が切れていないか Logs を確認。実行中の DB 障害は `/intro-config` の更新失敗を引き起こすが、メモリ上の設定で投稿動作は継続する |

詳細なエラー処理仕様は [SPEC.md § 3.7](../SPEC.md#37-エラーハンドリング) を参照。
